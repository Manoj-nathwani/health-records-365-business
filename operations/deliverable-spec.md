# Deliverable specification

**Status: not yet written.**

## What this doc must answer

- Which of the conceptual [outputs](../product/outputs.md) are in the first version, and which wait
- The component list and running order — the equivalent of [Chronicle's named pack](../market/competitors/chronicle-health.md)
- Format: what is a document, what is a table, what is interactive, what is a source file
- Depth: how long is a reconstructed history for a customer with 30 years of records?
- How [uncertainty](../product/uncertainty.md) and [open items](../product/open-loops.md) are visually distinguished from settled fact
- How provenance is shown at the point of claim
- What the customer gets on day one versus what accrues over the year

## Why it blocks

We cannot [price](../commercial/pricing.md), sell or QA an unspecified thing. Advisers cannot describe it. The [sample pack](./sample-pack.md) is this spec made concrete.

## Constraint

Every component must stay inside [the regulatory boundary](../trust/regulatory-boundary.md) — statements about the record, never clinical recommendation.
