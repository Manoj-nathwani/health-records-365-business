# Website strategy

Source: [Master Business Blueprint](../Inbox/health-records-365-business-blueprint.md) §25.

The website should have **one broad homepage plus problem-specific landing pages**.

> Do not make "moving abroad" the entire company. It is a strong acquisition wedge inside a broader proposition.

## Navigation

- **How it works**
- **Services**
- **Moving abroad**
- **International living**
- **Trust & privacy**
- **About**
- **Get started**

Under **Services**:

- Organise my medical history
- Ongoing record management
- Prepare for a doctor or specialist
- Treatment and healthcare abroad

These map to the [core offerings](../commercial/offerings.md).

## Three homepage pathways

1. **Organise my medical history**
2. **I'm moving abroad**
3. **I receive care in different places**

All three funnel into the same underlying service. See the [homepage narrative](./homepage.md).

## Landing-page backlog

Organised around customer situations, not separate sub-products. Draft each in [landing pages](./landing-pages/) using the `landing-page` template.

| Route | Trigger |
| --- | --- |
| `/organise-medical-records` | "I have years of records and no idea what they say." |
| `/nhs-and-private-healthcare` | "I use NHS and private healthcare." |
| `/moving-abroad` | "I'm leaving the UK." |
| `/moving-to-dubai` | "I'm leaving the UK." — the [launch wedge](../go-to-market/launch-wedge.md) |
| `/moving-to-spain` | "I'm leaving the UK." |
| `/moving-to-portugal` | "I'm leaving the UK." |
| `/already-living-abroad` | "I've already moved abroad." |
| `/international-health-records` | "My care spans several countries." |

| `/second-opinion` | "I want a second opinion." |

Which countries deserve pages first is [an open question](../go-to-market/open-questions.md) — build `/moving-to-dubai` first, since it matches the launch wedge.
